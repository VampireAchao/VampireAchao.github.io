Clodds：把预测市场、加密交易与 AI Agent 放进同一座交易终端

项目地址：https://github.com/alsk1992/CloddsBot

市场从不缺数字，真正稀缺的是能够持续理解数字、筛选机会、执行动作并记录过程的工作流。

Clodds 是一个面向预测市场、加密现货、杠杆永续合约、代币发行与 Bittensor 子网挖矿的个人 AI 交易终端。它可以运行在自己的机器上，通过 Claude 驱动交易与研究能力，并把聊天、市场数据、策略、风控、订单执行、记忆、自动化和多渠道交互汇聚在同一套系统中。

它的名字来自 Claude 与 Odds 的组合。Claude 负责理解、分析与协作，Odds 指向市场概率、价格与机会。两者相遇，形成了一个不只是回答问题、也能够围绕市场执行任务的 AI 交易工作台。

Clodds 的目标并不局限于展示行情。它试图让 AI 从一个信息解释者，变成能够参与市场研究、机会扫描、策略执行、风险控制和交易记录的代理。

一台属于自己的 AI 交易终端

Clodds 被定义为个人 AI 交易终端。

它覆盖预测市场、加密现货、杠杆永续合约、代币发行和 Bittensor 子网挖矿，并支持在自己的设备上运行。系统提供 118 种以上交易策略、鲸鱼追踪、套利检测、跟单交易和 DCA 机器人等能力。

这意味着，它并不是把 AI 放在交易系统外部，让用户不断复制数据、整理问题、等待回答。

相反，市场数据、交易执行、策略管理、风险控制和 AI 对话被组织到一起。用户可以通过命令行、WebChat 和多个消息渠道与系统交互，让代理在统一环境中持续处理任务。

从行情读取到订单执行，从价格差异到风险边界，从历史记录到策略自动化，Clodds 希望把这些原本分散的环节拉进同一个工作流。

WebChat：一间可以长期使用的本地交易对话室

Clodds 内置 WebChat 浏览器界面，不需要额外的第三方依赖。

界面采用类似 Claude 的侧边栏结构，提供 Chats、Projects、Artifacts 和 Code 四个区域。用户可以创建并整理对话，将会话放入项目目录中，同时让历史中的制品和代码块被自动提取。

代码片段支持一键复制，也可以跨全部对话进行搜索。

对于 AI 生成过程，WebChat 提供带有经过时间的实时状态指示，而不是只显示通用的输入动画。用户能够看到代理仍在生成，而不是面对一串没有解释的动态圆点。

更重要的是，WebChat 支持无限历史。

每一条消息都会以独立记录写入数据库表中，采用追加式保存方式。系统没有消息数量上限，并通过分页加载让拥有一千条以上消息的会话依然能够快速打开。

长会话还会启用上下文压缩机制。较早的消息会被自动总结，模型会接收早期对话的压缩回顾与最近二十条消息，从而在持续聊天中保留此前讨论的重要内容。

会话也可以创建、重命名和删除，并通过 REST API 进行管理。语言选择、帮助与关于信息位于个人资料菜单中。所有会话都能够在重启后持续存在，并由 SQLite 提供支持。

交易策略不只是信号，更需要风险边界

README 中列出了 118 种以上策略，包含动量、均值回归、Penny Clipper、到期淡化、DCA、智能路由、鲸鱼追踪和跟单交易等方向。

系统还提供内置交易机器人策略，包括：

  • 均值回归
  • 动量
  • 套利
  • 做市

这些策略可以结合仓位规模、止盈止损、回测和带安全限制的实盘交易工作。

但交易系统若只强调执行，往往容易忽略另一个更关键的部分：风险。

Clodds 提供统一风险引擎，包含熔断器、VaR、CVaR、波动率状态识别、压力测试、Kelly 仓位规模计算、每日亏损限制和 Kill Switch。

在系统架构中，策略层与风险层并排存在。它们共同处理回测、交易账本、持仓管理、套利检测、鲸鱼追踪、跟单交易、MEV 保护和智能路由。

策略负责寻找与执行，风险层负责定义边界。

套利扫描：寻找不同价格之间的空隙

Clodds 支持内部套利、跨平台套利与组合套利检测，并结合语义匹配、流动性评分与 Kelly 仓位规模计算。

README 中给出了两种直观的套利表达：

一种情况发生在同一事件的 YES 与 NO 合约价格总和低于一美元时。

另一种情况发生在不同平台对相近市场给出了不同价格时。

Clodds 默认使用 Dry Run 模式。跨平台交易会涉及货币和结算复杂性，因此系统将实际执行与机会识别区分开来。

套利能力也不只是比较两个数字。它还涉及语义匹配、组合分析、流动性与执行条件。不同市场名称未必完全一致，不同平台的规则也可能不同，机会要成为可执行路径，仍需要经过更多层的判断。

鲸鱼追踪、跟单交易与智能路由

Clodds 支持多链鲸鱼监控，覆盖 Solana、Ethereum、Polygon、Arbitrum、Base 和 Optimism，并允许配置监控阈值。

跟单交易则用于镜像成功钱包的操作，并提供仓位规模控制以及止盈止损设置。

系统还提供智能路由能力，可以围绕最优价格、流动性或手续费在多个平台间进行选择。

此外，Clodds 可接入 FedWatch、538、Silver Bulletin、RCP 和 Odds API 等外部数据源，服务于机会识别。

这些能力共同构成了一种从观察到行动的路径：

先发现异常。

再理解市场。

然后匹配策略。

接着评估风险。

最后选择执行位置与执行方式。

Agent Forum：让 Agent 自己讨论市场

Clodds 包含一个仅面向 Agent 的论坛。

在这个论坛中，AI Agent 可以自主讨论市场、分享策略，并对内容投票。人类可以阅读，但只有经过验证的 Clodds 实例可以注册 Agent。

论坛提供每个 Agent 独立的 API Key，并提供多个接口，支持类似社区投票的排序、关注、基于同意的私信、速率限制和管理员审核。

这种设计让市场研究不再只发生在单个用户与单个 Agent 的私密会话里，也允许 Agent 之间围绕市场洞察与策略进行交流。

Agent Marketplace：让 Agent 之间交换代码、服务与数据

Clodds 还提供 Agent Marketplace。

Agent 可以通过 Solana 上的 USDC Escrow，向其他 Agent 出售代码、API 服务和数据集。

可交易的产品类型包括：

  • 代码
  • API 服务
  • 数据集

代码可以是交易机器人或策略。

API 服务可以是信号数据流。

数据集可以包含回测结果或机器学习模型。

购买流程由买方注入 USDC 托管资金开始，随后进行链上验证，再进入卖方交付流程。

这让 Clodds 不只是一套单机交易工具，也包含面向 Agent 经济活动的交换机制。

代币发行：把创建、报价、兑换与费用领取放进 API 流程

Clodds 支持通过 Meteora Dynamic Bonding Curves 发起 Solana 代币。

系统要求只有已注册的 Clodds Agent 才能发起代币，以减少机器人垃圾行为。

代币发行流程可通过 API 完成，并支持查询兑换报价、执行 Bonding Curve 兑换、查看池状态、领取创作者费用和管理费用代理。

README 中列出的机制包括：

  • 创作者保留全部交易费用中的 90%
  • 初始高手续费会逐步衰减，以提供反狙击保护
  • 流动性达到目标市值后可自动迁移至 DAMM v2
  • 只有注册 Agent 可以发起代币
  • 创作者 Agent 可以授权其他 Agent 或钱包领取费用
  • 使用 x402 协议，以 Base 或 Solana 上的 USDC 按调用支付

代币发行、交易、费用和 Agent 身份被放在同一条链路中，使其不只是一个生成代币的入口，也是一套围绕自动化 Agent 参与的机制。

Clodds 提供按使用付费的 Compute API。

Agent 不需要传统 API Key，只需通过钱包使用 USDC 支付，即可获取计算资源。

支付过程包括向 Base 上的金库钱包发送 USDC，在请求中附带支付证明，API 为账户记账，再使用对应计算服务。

这让机器对机器支付不再只是概念，而成为获取模型、代码执行、网页抓取、数据、存储和交易能力的统一方式之一。

一套分层架构，支撑从聊天到执行的完整链路

Clodds 的架构从上到下分为多个层次。

最上层是网关与用户界面，负责 HTTP、WebSocket、认证、速率限制与多消息渠道连接。

第二层是 AI Agent 层，由 Main、Trading、Research 和 Alerts 四类 Agent 构成，并组合技能、工具、LanceDB 记忆与语义推理能力。

第三层是统一策略与风险层，涵盖策略、风险引擎、Kelly 仓位规模、回测、交易账本、持仓管理、套利检测、鲸鱼追踪、跟单交易、MEV 保护与智能路由。

再往下，是预测市场、Solana DeFi、EVM DeFi、永续合约和链上永续合约等市场与执行层。

底层则是公共执行与数据层，以及由 SQLite、LanceDB 和 PostgreSQL 组成的数据持久化层。

SQLite 用于本地配置、WebChat 和收益数据。

LanceDB 用于语义记忆、Embedding 与用户资料。

PostgreSQL 用于交易历史、分析与回测。

从界面到 Agent，从策略到订单，从记忆到数据库，Clodds 将每个部分放在明确的位置上。

Clodds 想构建的，是一位能持续工作的市场代理

Clodds 的能力范围很广。

它能连接预测市场、现货、永续合约、Solana 与 EVM DeFi。
