思源笔记：让知识在块与块之间生长，让人与智能体在同一处协作

项目地址：https://github.com/siyuan-note/siyuan

知识管理这件事，看起来像是在记录，实际上却更像是在照料一座不断扩张的花园。

一段灵感、一条资料、一页读书笔记、一份项目计划、一张截图、一份 PDF 标注，最初往往只是孤零零地落在某个角落。时间一长，它们会开始彼此呼应、彼此牵引，慢慢长成一张属于自己的知识网络。

思源笔记是一款开源、隐私优先、支持自托管的个人知识管理系统。它将知识工作空间看作人与智能体能够共同工作的地方，也把笔记从单纯的文档，延展为可以引用、查询、关联、组织和持续沉淀的内容世界。

它的核心理念可以概括为一句话：

从思考走向洞见，并让智能体参与其中。

从文档走向内容块

传统笔记习惯把内容装进一篇篇文档里。文档当然重要，但当笔记不断积累时，人们真正想要复用的，常常不是整篇文章，而是其中某一个段落、一条定义、一份清单、一个结论，或是一段尚未完成的想法。

思源笔记以内容块为基础组织知识。

段落可以成为独立的内容单元。

列表中的条目可以成为独立的内容单元。

文档中的任何一块内容，都能够被细粒度地引用和连接。

这种方式让笔记不必总是沿着线性的阅读顺序存在。一个想法可以从原来的位置被引用到新的上下文中，一段资料可以在多个主题下发挥作用，而不是被复制出越来越多难以维护的版本。

当内容开始以块为单位被看见，知识就拥有了更灵活的流动方式。

双向链接，让笔记知道自己曾经去过哪里

知识并不总是按照文件夹的方式生长。

有些内容属于同一个项目，有些内容围绕同一个概念，有些内容则在很久之后才显现出关联。思源笔记提供了块级引用与双向链接，让这些关系不再只能依赖记忆维系。

你可以从一段内容指向另一段内容。

也可以回过头来查看，哪些地方曾经引用过它、提及过它。

于是，笔记不再是一排沉默的文件。它们会留下相遇的痕迹，像一条条可追溯的路径，把分散在不同时间、不同主题和不同文档中的内容慢慢串联起来。

对于长期积累知识的人来说，这种连接尤其重要。它让过去写下的内容不只是被保存下来，也能够在新的思考中重新出现。

所见即所得，但依然站在 Markdown 的土地上

思源笔记支持 Markdown 所见即所得编辑。

这意味着，写作时不必总是在源码与预览之间切换，也不必为了看见最终排版不断打断思路。标题、列表、引用、公式、图表和内容块可以在编辑过程中自然呈现，让书写更接近直觉。

与此同时，Markdown 依然是重要的内容表达方式。

思源笔记支持导出包含资源文件的标准 Markdown，也支持导出 PDF、Word 和 HTML。对于需要把笔记带出工作空间、整理为不同交付形式的人来说，内容不必被困在单一的界面之中。

在这里，Markdown 像一层安静的底色，既支撑内容表达，也让知识拥有更清晰的文本形态。

不只是写字，而是让复杂内容安稳落地

知识管理并不总是由纯文字组成。

有时需要写公式。

有时需要整理图表。

有时需要画流程图、甘特图、时序图，甚至记录乐谱。

有时需要编辑超长文档，也需要在一个局部内容块中放大观察。

思源笔记提供了面向这些场景的编辑能力，包括列表大纲、块缩放、百万字大文档编辑，以及数学公式、图表、流程图、甘特图、时序图和乐谱等内容形式。

这让笔记可以不止承担随手记录的角色。

它也可以承接更系统的学习笔记、更复杂的项目资料、更长篇的写作内容，以及需要反复梳理结构的知识材料。

当内容的表达形式越来越丰富，笔记也就不再只是一个输入框，而更像是一张能够容纳思维展开过程的工作台。

让资料不只停留在外部世界

很多信息并不从键盘开始。

网页里的文章值得保存。

PDF 里的标注值得回看。

图片中的文字有时也需要被识别和利用。

思源笔记支持网页剪藏、PDF 标注链接与 Tesseract OCR。它让外部资料能够进入知识工作空间，并在之后继续参与整理、引用和关联。

网页剪藏可以把浏览过程中的内容带回笔记。

PDF 标注链接让阅读资料时留下的痕迹，不必停留在文档内部。

OCR 则为图像中的文字提供了进一步进入内容流的可能。

知识管理并不只是整理自己写下的东西，也是在不断接住外部世界带来的信息。思源笔记希望让这些信息进入之后，不只是被存放，而是能继续被使用。

查询，让积累变得可被发现

笔记越多，检索就越重要。

思源笔记支持 SQL 查询嵌入，也提供搜索与 SQL 相关能力。内容块、自定义属性、标签、书签、模板片段，以及其他工作空间中的信息，都能够成为组织和查找知识的线索。

当知识库逐渐庞大时，人们不一定记得某个内容放在哪一篇笔记里，但可能记得其中一个关键词、一段表述、某个属性或一组关联。

查询能力就像在知识空间里点亮一盏灯。

它不是替代写作，而是让已经写下的内容更容易重新被发现。

表格视图与闪卡复习，让知识不只被收藏

记录不等于掌握。

资料被收集之后，还需要被整理、被回顾，也需要在适当的时候重新出现。

思源笔记提供数据库表格视图，也支持闪卡间隔重复。前者让内容能够以表格方式被管理，后者则把知识复习纳入工作空间之中。

表格视图适合承接结构化内容。

闪卡间隔重复则适合让需要记忆和巩固的内容，在不同时间重新回到眼前。

于是，知识库不只是一个保存过去的仓库。它也可以成为一个会提醒、会组织、会帮助人重新面对旧内容的空间。

AI 写作与问答聊天，走进日常笔记流

思源笔记支持通过 OpenAI API 进行 AI 写作与问答聊天。

这让智能能力不必漂浮在笔记之外。它可以进入日常记录、写作与提问的过程，成为知识工作空间中的一个参与者。

人与智能体在同一处协作，并不意味着笔记被交给自动化处理，而是让写作、提问、整理和思考拥有更多可调用的能力。

当一个想法刚刚出现时，可以先记录下来。

当一段内容需要继续展开时，可以进入写作过程。

当知识库中积累了大量材料时，也可以通过问答的方式重新与这些内容发生互动。

思源笔记所描绘的，并不是一个只负责存放内容的工具，而是一个让思考持续运转的知识空间。

多标签与分屏，让不同线索同时展开

真实的知识工作很少只有一条线。

写项目方案时，可能需要同时查看会议记录、需求清单和参考资料。

整理读书笔记时，可能需要一边回顾章节摘要，一边补充自己的想法。

思源笔记支持多标签，并支持通过拖放拆分屏幕。不同内容可以在同一个工作空间中并排展开，让思维不必总在窗口之间来回跳转。

当多个线索同时摆在眼前，关联会更容易被发现。

当资料、草稿与引用内容能够并排出现，写作和整理的节奏也会更连贯。

模板、代码片段与社区集市

重复性的记录，总会消耗不必要的精力。

思源笔记提供模板片段，也支持 JavaScript 与 CSS 片段。对于需要反复使用相似结构的人来说，模板可以让固定的内容框架更快出现；而代码片段则为进一步调整和扩展提供了空间。

项目还提供社区集市。

插件、挂件与其他扩展能力可以在这里被保存和使用。知识工作空间并不总是固定不变的，它会随着记录方式、写作习惯与个人需求不断调整。社区集市让这种变化拥有了可以延展的方向。

数据留在工作空间里

隐私优先，是思源笔记的重要定位。

它将数据保存在工作空间的数据文件夹中。资源文件、表情图片、代码片段、查询条件、布局、闪卡、模板、挂件、插件与公开数据，都有各自对应的位置。用户创建的笔记本则保存在其他目录中，笔记本内以 .sy 为后缀的文件保存文档数据，数据格式为 JSON。

这种组织方式让工作空间本身成为知识的承载地。

资源放在 assets 中。

表情图片放在 emojis 中。

代码片段放在 snippets 中。

查询条件、布局和闪卡等内容放在 storage 中。

模板片段放在 templates 中。

挂件放在 widgets 中。

插件放在 plugins 中。

公开数据放在 public 中。

这些目录并不是抽象的概念，而是知识工作空间的组成部分。它们共同承接日常积累下来的文字、附件、设置、模板与扩展。

对于需要批量处理、脚本化调用或直接检查工作空间数据的人来说，命令行让知识库不只存在于图形界面中，也能够进入终端工作流。

跨越桌面、移动端与不同系统

思源笔记提供 Android、iOS 与 HarmonyOS 应用，也支持 Docker 部署。

它的生态中包含编辑器引擎、浏览器扩展、社区集市、数据仓库、插件 API、Android 应用、iOS 应用、HarmonyOS 应用与间隔重复相关项目。

这让思源笔记不只是一个独立的笔记应用，而是围绕知识记录、编辑、扩展、数据与复习逐步展开的一组能力。

无论是坐在桌面前进行长篇写作，还是在移动设备上记录片段想法，知识都可以继续回到同一个工作空间中。

大多数功能免费，也可用于商业用途

思源笔记的大多数功能免费，并且可以用于商业用途。

同时，部分功能属于付费会员权益。

这种安排让基础的知识记录、编辑、连接、查询、导出与部署能力能够服务于更广泛的使用场景，也让需要会员权益的人拥有相应的选择。

让笔记成为持续思考的地方

思源笔记的价值，不只在于它支持多少种编辑方式，也不只在于它可以保存多少内容。

它更像是在回答一个问题：

当我们已经积累了越来越多的文字、资料、想法与关联之后，如何让它们不只是留在过去，而是继续帮助今天的思考。

内容块让笔记拥有更细粒度的生命。

双向链接让分散内容能够彼此发现。

Markdown 所见即所得编辑让写作保持流畅。

查询、表格视图与闪卡复习让积累可以被重新调用。

网页剪藏、PDF 标注链接与 OCR 让外部资料进入知识空间。

AI 写作与问答聊天让智能体能够参与知识工作。

自托管与工作空间数据结构，则让知识拥有更清晰的落脚之处。

思源笔记像一座不断生长的知识花园。每一次记录都是播种，每一次引用都是连根，每一次回顾都是浇灌。最终，那些曾经零散的内容，会在块与块之间慢慢形成路径，并把思考带向更深的地方。
