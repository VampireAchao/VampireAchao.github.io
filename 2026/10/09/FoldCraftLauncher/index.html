Fold Craft Launcher：让 Minecraft Java Edition 在 Android 上拥有一座完整的启动入口

项目地址：https://github.com/FCL-Team/FoldCraftLauncher

在许多玩家心中，Minecraft Java Edition 不只是一个游戏名称，更像是一片持续生长的世界：版本不断推进，模组加载器不断演化，材质、光影、存档与整合包也在各自的轨道上延展。对于 Android 平台而言，如何将这些内容汇聚到一个稳定、清晰、可管理的入口中，是一件并不轻松的事。

Fold Craft Launcher 正是为此而来。

这是由 FCL 团队开发的 Android 平台 Minecraft Java Edition 启动器。它基于 HMCL 的核心功能，并使用 Amethyst-Android 提供 JVM 启动与渲染后端相关能力。它试图做的并不只是启动一次游戏，而是将版本、运行时、控制方式、资源内容、主题外观与渲染扩展组织在一起，让 Android 设备上的 Minecraft Java Edition 体验拥有更完整的起点。

从启动游戏开始，也不止于启动游戏

启动器往往是玩家进入游戏世界前最先见到的界面。

它像一扇门。门后可能是熟悉的原版世界，也可能是加入模组后的全新冒险；可能是一次短暂的登录，也可能是一段漫长存档的延续。Fold Craft Launcher 将这扇门安放在 Android 平台上，让 Minecraft Java Edition 的启动、版本选择与资源管理能够集中在同一个应用之中。

项目描述非常明确：Fold Craft Launcher 是一款 Android Minecraft Java Edition 启动器。

而在 README 所呈现的功能范围中，它并没有停留在单一版本或单一玩法之中。它原生支持 Minecraft 全版本，也包括最新快照版本。对于希望在不同版本之间切换的用户来说，启动器不再只是一个固定入口，而是通向不同游戏阶段的一条通道。

旧版本承载着过去的玩法与记忆，新版本带来不断更新的内容，快照版本则让玩家可以更早接近正在变化的 Minecraft。Fold Craft Launcher 将这些版本放进支持范围之中，让选择本身成为启动体验的一部分。

面向多种模组加载方式

Minecraft Java Edition 的世界并不只由游戏本体构成。

模组加载器让玩法拥有了更多延展空间，也让不同版本、不同社区与不同内容组合拥有各自的运行方式。Fold Craft Launcher 支持 Forge、NeoForge、LiteLoader、OptiFine、Fabric、Quilt 与 Cleanroom 等模组加载器。

这些名称背后，是不同的模组生态与使用路径。对启动器而言，支持它们意味着面对更多样的版本组合与运行需求。Fold Craft Launcher 将这些加载器纳入支持范围，使玩家能够在 Android 平台上面对更丰富的 Minecraft Java Edition 启动选择。

当原版世界足够纯粹时，可以回到最直接的游戏体验。

当模组内容需要被装载时，启动器也能够成为连接版本与加载器的入口。

多版本 Java 运行时，为不同游戏版本准备

Minecraft Java Edition 的运行离不开 Java。

Fold Craft Launcher 内置 Java 8、Java 17、Java 21 与 Java 25 多个版本的运行时，同时也支持导入 Java。这样的设计让运行环境不必被单一版本固定，而是能够围绕不同游戏版本与使用需求进行选择。

在启动器的世界里，Java 并不是一个遥远的底层概念。它直接关系到游戏如何被启动，也关系到不同版本如何获得对应的运行环境。Fold Craft Launcher 将多个 Java 运行时放入应用能力之中，同时保留导入 Java 的支持，让运行时管理成为启动体验中的一个清晰部分。

这份能力并不喧闹，却像一组已经整理好的工具。需要时，它们就在这里。

让触摸操作拥有自己的语言

Android 设备拥有自己的交互方式。

屏幕触控、虚拟按键与手势，是移动设备最自然的操作语言。Minecraft Java Edition 的操作逻辑则有另一套传统：鼠标、键盘与大量需要精准触发的按键行为。两种交互方式相遇时，启动器需要承担一部分连接工作。

Fold Craft Launcher 提供虚拟鼠标与自定义按键映射。

虚拟鼠标为触控环境带来更接近指针操作的方式，自定义按键映射则让控制布局可以按照使用习惯进行安排。玩家不必只面对单一固定的控制模式，而可以在自己的设备与自己的操作节奏之间寻找更合适的组合。

项目还支持 FCL 与 ZalithLauncher2 控制布局互转。当导入 ZalithLauncher2 布局时，应用会自动进行转换。

布局本身并不只是按键的位置。它也是一次次点击、移动、切换物品与调整视角所形成的操作记忆。能够在不同控制布局之间转换，意味着这份记忆不必完全从零开始。

光影、渲染器与画面的另一面

Minecraft 的方块世界简单，却并不意味着它只能以一种方式被呈现。

光线、阴影、材质与渲染方式，都会为同一片地形带来不同的视觉气息。Fold Craft Launcher 支持光影，但这一能力需要 VirGL、Zink 或 MG 渲染器。

光影支持让画面表现拥有更多可能性，而渲染器则是这份可能性得以落地的重要一环。项目同时支持渲染器插件化，为渲染能力保留了可扩展的空间。

这让启动器不只负责把游戏运行起来，也为画面呈现预留了更多路径。

在 README 的使用截图中，项目展示了浅色界面、深色界面以及游戏画面。它们共同勾勒出 Fold Craft Launcher 的形态：启动器本身拥有清晰的界面风格，而游戏则在另一侧等待被打开。

把资源放回可管理的位置

一段 Minecraft 体验往往不会只包含一个游戏版本。

模组会改变内容，整合包会组织玩法，材质会重塑视觉，光影会调整氛围，存档则沉淀时间。它们并不是彼此孤立的文件，而是游戏体验中真实存在的组成部分。

Fold Craft Launcher 提供动态资源管理，覆盖模组、整合包、材质、光影与存档。

这意味着启动器不只是一个按下启动按钮的地方，也承担着资源管理的角色。不同内容被放入同一个管理视野中，玩家可以围绕自己的游戏环境进行整理与选择。

当一个世界不断积累内容时，管理能力往往会变得重要。Fold Craft Launcher 将这部分工作纳入自身功能范围，让版本之外的资源也拥有归处。

主题可以跟随个人偏好变化

工具的功能决定它能做什么，外观则决定它以怎样的姿态陪伴使用者。

Fold Craft Launcher 支持个性化主题定制，能够调整背景与颜色方案。浅色界面与深色界面的展示，也让这一点有了更直观的呈现。

主题不是游戏内容本身，却能让启动器的日常使用拥有不同的氛围。

有人喜欢明亮清晰的界面，有人更习惯深色背景下的沉静。背景与配色的变化，让启动器不再只有一种固定面貌，而可以更贴近用户自己的视觉偏好。

这是一种轻量但真实的自由：在进入方块世界之前，先让入口看起来更像自己习惯的样子。

站在多个开源项目的连接处

Fold Craft Launcher 的组成并非来自单一方向。

README 列出了项目所关联和依赖的多个开源项目。其中，HMCL 为核心功能来源，fclcore 移植自 org.jackhuang.hmcl。Amethyst-Android 作为 PojavLauncher 的 Android 分支，承担 JVM 启动与渲染后端相关角色。

项目也列出了 Boat 及其相关项目、authlib-injector、EasyTier、Terracotta、TouchController、NG-GL4ES、FCLRendererPlugin 与 FCLDriverPlugin 等相关项目。

在依赖层面，README 中还包括 Android Support Libraries、GL4ES、ANGLE、OpenJDK、LWJGL3、LWJGLX、Mesa 3D Graphics Library、SPIRV-Cross、bhook、libepoxy、virglrenderer、OpenAL-Soft、oboe、pfffft、discord-rpc 与 control-converter 等内容。

这些项目与组件共同构成了 Fold Craft Launcher 所依托的技术背景。启动器呈现在用户面前时，是一套面向 Android 的 Minecraft Java Edition 使用体验；而在它背后，则是一系列核心功能、运行时、图形、音频、控制与网络相关能力的汇集。

开源，也允许更多语言加入

Fold Craft Launcher 使用 GPL-3.0 License 授权。

项目同时通过 Weblate 管理本地化翻译。翻译参与不需要安装额外工具，可以直接在网页端进行贡献。对于一款面向不同地区用户的启动器而言，多语言并不是装饰性的附加项，而是让更多人能够理解、使用并参与项目的一部分。

简体中文、英文与俄语 README 的并列出现，也让项目的语言视野更加清晰。不同语言承载的不只是文字转换，还意味着同一个启动器可以被更多玩家以熟悉的方式阅读和理解。

一座通往方块世界的移动入口

Fold Craft Launcher 的定位始终很明确：它是一款 Android 平台上的 Minecraft Java Edition 启动器。

但当功能被逐一展开时，这个定位也拥有了更具体的轮廓。

它支持 Minecraft 全版本与最新快照。

它覆盖 Forge、NeoForge、LiteLoader、OptiFine、Fabric、Quilt 与 Cleanroom 等模组加载器。

它提供 Java 8、Java 17、Java 21 与 Java 25 运行时，也支持导入 Java。

它为触控设备准备了虚拟鼠标与自定义按键映射，并支持 FCL 与 ZalithLauncher2 控制布局互转。

它能够管理模组、整合包、材质、光影与存档。

它支持主题背景与颜色方案定制。

它支持在特定渲染器条件下使用光影，也支持渲染器插件化。

于是，Fold Craft Launcher 不再只是一个单纯的启动按钮。它更像是一座被安放在 Android 设备上的入口，将版本、资源、控制、运行时与界面体验汇聚在一起。

当玩家准备进入 Minecraft Java Edition 的世界时，这座入口已经在屏幕上等候。
