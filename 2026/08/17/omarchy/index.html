Omarchy：一套有明确态度的现代 Linux 发行版

在 Linux 的世界里，选择往往很多，答案却未必清晰。Omarchy 从一开始就没有把自己塑造成包罗万象的集合体，而是用一句简洁的描述亮明方向：它是一套美观、现代且有明确取向的 Linux 发行版。

它由 DHH 打造。这里的“有明确取向”并不是一句装饰性的形容，而像是一种清晰的设计姿态：Omarchy 不试图在每一个方向上都保持模糊而宽泛的中立，它希望将一套完整的桌面使用体验组织起来，让系统、工具、界面、配置与日常动作彼此呼应。

项目地址：https://github.com/basecamp/omarchy

从一套发行版，到一部可持续阅读的手册

Omarchy 的 README 没有堆砌冗长的介绍，而是把目光投向了另一项更重要的内容：Omarchy Manual。

这份手册的权威来源位于项目中的 manual/ 目录。它不是零散说明的拼接，也不是只覆盖安装阶段的快速指南，而是一条从初次接触到持续使用、从桌面操作到配置维护的完整阅读路径。

手册从欢迎页面开始，像为刚刚走进 Omarchy 世界的人打开一扇门。随后，内容进入系统使用最常见、也最贴近日常节奏的部分。

从开始使用，到熟悉桌面节奏

对于任何桌面系统来说，真正重要的不只是能否启动，而是人能否自然地在其中移动、操作、切换与停留。Omarchy 的手册将这些基础体验单独整理出来，包括：

  • 开始使用
  • 从 Mac 或 Windows 迁移而来
  • 导航
  • 顶部栏
  • 主题
  • 快捷键
  • 统一剪贴板与历史记录
  • 提醒事项
  • 通知
  • 文本提取与听写
  • 截图与录制
  • 开关、空闲状态与屏幕保护
  • Omarchy CLI

这些章节名称本身就勾勒出一个桌面环境的日常轮廓。

导航决定人在系统里如何穿行。顶部栏像始终停留在视野边缘的秩序线。主题负责让视觉语言形成统一气质。快捷键则把重复动作压缩成更短、更直接的节奏。剪贴板历史、提醒与通知，让曾经复制过的内容、需要记住的事情与正在发生的信息，都能够在需要时重新出现。

文本提取与听写、截图与录制，则将输入、捕捉和表达纳入桌面体验之中。空闲状态、屏幕保护与各种开关，看似位于使用流程的边缘，却也构成了系统陪伴用户时不可缺少的一部分。

而 Omarchy CLI 的存在，让这套桌面体验并不只停留在图形界面里。它同样拥有面向命令行的入口，使操作方式能够在不同习惯之间延展。

应用不是孤岛，而是工作环境的一部分

Omarchy 手册中有一个清晰的应用章节。它没有只列出某一类工具，而是把终端、编辑器、人工智能、开发工具、Shell 工具、终端界面应用、图形界面应用、浏览器、Web 应用、商业应用与服务等内容并列呈现。

其中包括：

  • Terminal
  • Neovim
  • AI
  • Development Tools
  • Shell Tools
  • Shell Functions
  • TUIs
  • GUIs
  • Browsers
  • Commercial apps and services
  • Web Apps
  • Gaming
  • Filling out PDFs
  • Windows VM
  • Other Packages

这样的目录像一张工作台，而不是一份孤立的软件清单。

终端与 Neovim 代表着偏向键盘与文本的工作方式。开发工具、Shell 工具与 Shell Functions 则让命令行环境拥有更具体的延展空间。TUI 与 GUI 并排出现，也意味着不同的交互形态都被放在同一张桌面地图上。

浏览器、Web 应用与商业应用及服务，让网络世界与本地系统相连。游戏、PDF 填写、Windows 虚拟机以及其他软件包，则把更多具体使用场景纳入手册范围。

Omarchy 在这里呈现出的并不是“只适合某一种人”的单一姿态，而是将多种使用需求放在一套有组织的环境中。无论是在终端里工作、在编辑器中写作、在图形应用中处理事务，还是需要浏览网页、运行 Web 应用、使用虚拟机，手册都为这些方向预留了章节。

配置，是让系统逐渐成为自己的过程

一套系统在刚安装完成时只是起点。真正的使用会不断带来新的偏好：显示器如何安排，键盘和鼠标如何响应，字体和背景如何选择，网络如何连接，提示符如何呈现，主题如何变化。

Omarchy 的配置部分覆盖了这些持续发生的调整：

  • 更新
  • Dotfiles
  • Shell 插件
  • 显示器
  • 键盘、鼠标与触控板
  • 网络
  • 系统休眠
  • 硬件认证
  • 字体
  • 背景
  • 提示符
  • 品牌标识
  • 常见调整
  • 更多主题
  • 创建自己的主题

这一部分尤其能体现 Omarchy 对“长期使用”的关注。

更新是系统保持变化的方式。Dotfiles 则与个人配置密切相关。Shell 插件、提示符和常见调整，让命令行环境也能逐渐贴近个人习惯。显示器、键盘、鼠标、触控板、网络与系统休眠，分别对应桌面设备和日常连接中的重要环节。

字体与背景影响每一次注视屏幕时的感受。主题与更多主题，为桌面视觉带来变化的空间。创建自己的主题，则把这种变化进一步交还给使用者。

当配置不再只是散落在不同位置的一连串修改，系统就更像一个可以持续塑形的空间。Omarchy 手册将这些内容集中起来，让调整不必完全依赖零散搜索与记忆。

不只关注开始，也关注迁移、维护与恢复

Omarchy 的手册并没有在基础操作和配置完成后戛然而止。它还保留了许多与系统长期运行相关的章节：

  • Mac 支持
  • 故障排除
  • 常见问题
  • 系统快照
  • 安全
  • Omarchy on
  • 双系统安装
  • 无人值守安装

这些主题让 Omarchy 的文档结构延伸得更远。

从 Mac 支持到双系统安装，手册考虑到了不同设备与不同安装状态。故障排除与常见问题，则为遇到阻碍时的回看留出位置。系统快照与安全，指向系统运行中更需要谨慎对待的部分。无人值守安装，则把安装过程延伸到更自动化的方向。

一份真正适合长期阅读的系统手册，不该只在一切顺利时才有价值。它同样应该在用户转换设备、调整环境、面对故障、考虑安全或重新部署时，继续成为可以回到的地方。Omarchy 将这些章节收纳进同一部手册，也让系统的叙事从“如何开始”延续到“如何持续”。

一份目录背后的完整感

Omarchy 的 README 传递出的信息并不复杂，却很集中。

它是一套美观、现代、有明确取向的 Linux 发行版。它由 DHH 打造。它拥有一部以项目内 manual/ 目录为权威来源的手册。手册覆盖桌面基础操作、应用、配置、迁移、维护、安全、快照、双系统安装与无人值守安装等主题。项目以 MIT License 发布。

这些信息组合在一起，勾勒出的并不只是一个仓库，而是一套试图将使用体验、工具选择、配置过程与文档路径连成整体的 Linux 发行版。

Omarchy 的名字背后，是一种对桌面环境的组织方式：让外观、现代感与明确态度站在同一侧，让系统不只是等待用户自行拼装的空白画布，也是一套已经开始形成自身语言的工作空间。
